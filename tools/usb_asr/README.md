# 0.4.3 固定“好的”回应（需配套固件0.4.3）

仅为明确接受的人声指令播放一次板载“好的”，不使用云端或运行时TTS。已激活重复叫名、自动待机、被拒绝语句不播放。回应期间约0.9秒暂停ASR，请听完并等“恢复识别”后再说下一条，不支持边播放边打断。

需要重新刷写配套0.4.3固件；将新pc合并到原目录保留venv/models，不用重新setup。运行start_control.cmd COM3，按Enter后看到0.4.3握手。详细安装/原理/实机待测见SPOKEN_OKAY_GUIDE.md或ZIP内docs/SPOKEN_OKAY.md。数字播放DONE不等于已验证实体扬声器，实际以听测为准。

# PC语音控制0.4.2（需配套固件0.4.2）

本次修复后台Listening普通日志回执超时：新固件管理20秒聆听/5秒表情展示，电脑不再每2秒发送控制指令；已激活时重复叫名称仅extend续期，不重置脸。控制使用带会话、序号、校验的原子回执，不再把普通日志当确认。

需要同时刷写完整0.4.2 usb_asr固件并更新pc文件。现有venv/models保留，不需要重装依赖或下载模型。将新pc合并到`D:\NOMI-ASR-debug`，在原pc目录运行`start_control.cmd COM3`，按Enter应看到0.4.2编号回执协议就绪。不要只更新PC后继续使用0.4.0固件。

先说“小米同学”/“你好小米同学”，再说“开心一点/开心一下”“难过一点/难过一下”“眨一下眼/眨眼一下”等。“休息一下”或20秒无有效指令回idle。仍为Windows本地ASR，临时/停止结果不执行，不做模糊匹配，不接AI/TTS/云端，不保存录音/转录。旧`start.cmd`保留纯转录。Ctrl+C退出，不同时开miniterm。

完整更新/烧录/词表/回执边界见`VOICE_CONTROL_GUIDE.md`或仓库`docs/PC_VOICE_CONTROL.md`。模型/依赖锁未变：sherpa-onnx及core2.0.1、NumPy2.2.6、pyserial3.5，64位Python3.10–3.13。首次安装才运行setup.cmd，建立独立venv并下载校验约21MB模型。权重/轮子不随源码更新包分发，许可说明与来源保持model.lock.json及上游不变；运行不使用电脑麦克风，不上传录音。
